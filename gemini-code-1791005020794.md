# Database Design Prompt (MySQL Schema & Architecture)

Act as a Senior Database Architect. Design a production-ready relational database schema using MySQL for a Multi-Vendor Computer Hardware & Laptop Marketplace.

## 1. Database Requirements
- **Engine:** InnoDB (ACID compliant with Foreign Key constraints and Transactions)
- **Character Set:** `utf8mb4` with `utf8mb4_unicode_ci` collation
- **Key Capabilities:**
  - Multi-vendor isolation (multiple shops selling different computer parts).
  - JSON specification support for PC hardware (Sockets, VRAM, TDP, Interface).
  - Financial auditability (tracking seller revenue, items sold, and platform metrics).

## 2. Table Schemas Required

1. **`users`**:
   - `id`, `name`, `email` (unique), `password`, `role` (`buyer`, `seller`, `admin`), `phone`, `avatar`, timestamps.
2. **`shops`**:
   - `id`, `seller_id` (1:1 with users, cascade on delete), `shop_name`, `description`, `logo`, `is_approved` (boolean), timestamps.
3. **`categories`**:
   - `id`, `name`, `slug` (unique), `icon` (e.g., CPU, GPU, RAM, Motherboard, Laptop).
4. **`products`**:
   - `id`, `shop_id` (foreign key), `category_id` (foreign key), `name`, `description`, `specifications` (JSON type for hardware parameters), `price`, `cost_price`, `stock_quantity`, `image_url`, timestamps.
5. **`orders`**:
   - `id`, `buyer_id` (foreign key), `total_amount`, `payment_status` (`pending`, `paid`, `failed`), `order_status` (`pending`, `processing`, `shipped`, `delivered`, `cancelled`), `shipping_address`, timestamps.
6. **`order_items`**:
   - `id`, `order_id` (foreign key, cascade on delete), `product_id` (foreign key), `shop_id` (foreign key for direct vendor revenue mapping), `quantity`, `price_each`.
7. **`site_analytics`**:
   - `id`, `visit_date` (unique date), `unique_visitors`, `page_views`.

## 3. Necessary SQL Queries to Deliver
- Provide the complete DDL script (`CREATE TABLE` statements with indexes and constraints).
- Write optimized analytical queries:
  1. Calculate net revenue and total units sold for a specific `shop_id`.
  2. Retrieve distinct customers who purchased from a specific seller with total spent.
  3. Admin query for Daily Active Visitors and platform Gross Merchandise Value (GMV).
