# Frontend Engineering Prompt (React.js + Tailwind CSS)

Act as a Senior Frontend React Developer and UI/UX Designer. Build the complete frontend application for a Multi-Vendor Computer Hardware & Laptop E-Commerce Platform.

## 1. Tech Stack & Libraries
- **Framework:** React.js (Vite)
- **Styling:** Tailwind CSS (Dark-Tech aesthetic: Slate-900 background, Slate-800 cards, Cyan & Indigo accents)
- **Icons:** Lucide React (`lucide-react`)
- **State Management & Routing:** React Context / Zustand, React Router Dom (`react-router-dom`)
- **HTTP Client:** Axios (configured with interceptors for JWT Bearer token)

## 2. Portals & Required Components

### A. Buyer Portal
1. **Catalog & Search Filter Sidebar (`/products`):**
   - Category selection (CPU, GPU, RAM, Laptop, Motherboard, PSU, Case, Storage).
   - Multi-spec hardware filters (Socket type, VRAM size, DDR generation, Brand, Price Range slider).
   - Responsive Product Grid with quick "Add to Cart" and stock badge indicators.
2. **Interactive Cart Drawer & Checkout (`/checkout`):**
   - Slide-in cart drawer grouped by Vendor/Shop.
   - Real-time calculations: Subtotal, Shipping fee, Tax (VAT), and Grand Total.
   - Checkout form with delivery address inputs and payment selector (Bakong KHQR / Card).
3. **Buyer Profile & Spending Dashboard (`/profile`):**
   - Total spent metric card and total completed orders counter.
   - Order history timeline with live status badges (`pending`, `shipped`, `delivered`).

### B. Seller Portal (`/seller`)
1. **Shop Registration & Profile Setup:**
   - Store name, description, logo upload, and contact info form.
2. **Product & Inventory Manager:**
   - Add/Edit product modal with dynamic JSON key-value input for hardware specs.
   - Stock level controls and "Low Stock Alert" warnings (< 5 units).
3. **Vendor Analytics Dashboard:**
   - 4 Metric cards: Total Revenue ($), Total Items Sold, Low Stock Alert, Unique Customers.
   - Recent customer purchase table: Buyer name, items bought, total price, order status.

### C. Super Admin Dashboard (`/admin`)
1. **Platform Analytics:**
   - Daily Active Users (DAU) metric and daily traffic chart overview.
   - Financial breakdown: Total marketplace GMV, platform commission, server expenses, net profit.
2. **Moderation Queue:**
   - Vendor store approval table with Approve / Reject action buttons.

## 3. Output Requirements
- Provide modular, production-ready React JSX/TSX code.
- Apply responsive Tailwind CSS utility classes with complete hover, active, and loading states.
- Mock Axios API calls cleanly with `useEffect` or React Query patterns.
